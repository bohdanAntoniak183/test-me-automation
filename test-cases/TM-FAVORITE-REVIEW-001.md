# TM-FAVORITE-REVIEW-001

**_Назва:_** Додавання товарів до обраного, оформлення замовлення та написання відгуку.

**_Пріоритет:_** Низький.

**_Тип_**: позитивний, наскрізний API-сценарій.

**_Покриття функціоналу:_** додавання товарів до обраного, оформлення замовлення, створення відгуку.

**_Передумови:_** API доступне; створено нове середовище через `POST /api/workspaces` (отримано валідний `X-Workspace-Token`).

**_Тестові дані:_** токен середовища; 1 термопляшка; 1 клавіатура; ім'я користувача ```«Олександр Тестовий»```; електронна адреса ```test@example.test```; адреса доставки ```«Київ, вул. Тестова, 12»```. Усі контактні дані вигадані.

| Крок | Дія | Очікуваний результат |
| ------------- | -------------- |--------------|
| 1 | Надіслати `GET /api/products`. | Отримано відповідь ```200 OK```. У списку продуктів отримати ідентифікатори термопляшки та клавіатури. |
| 2 | Надіслати `PUT /api/favorites` для додавання термопляшки до обраного із тілом запиту:<br />```{'product_ids: ["<ідентифікатор термопляшки>"]'}``` | Отримано відповідь ```200 OK```. Тіло відповіді запиту збігається з тілом самого запиту. |
| 3 | Надіслати `GET /api/favorites` для отримання списку обраних продуктів. | Отримано відповідь ```200 OK```. Тіло відповіді запиту збігається з раніше надісланим запитом у кроці 2. |
| 4 | Надіслати `PUT /api/favorites` для додавання клавіатури до обраного із тілом запиту:<br />```{'product_ids: ["<ідентифікатор термопляшки>", "<ідентифікатор клавіатури>"]'}``` | Отримано відповідь ```200 OK```. Тіло відповіді запиту збігається з тілом самого запиту. |
| 5 | Надіслати `GET /api/favorites` для отримання списку обраних продуктів. | Отримано відповідь ```200 OK```. Тіло відповіді запиту збігається з раніше надісланим запитом у кроці 4. |
| 6 | Надіслати `POST /api/orders` для із тілом запиту:<br />```{'items': [{'product_id': '<ідентифікатор термопляшки>', 'quantity': 1}, {'product_id': '<ідентифікатор клавіатури>', 'quantity': 1}], 'name': 'Олександр Тестовий', 'email': 'test@example.test', 'address': "Київ, вул. Тестова, 12", 'delivery': 'standard', 'payment': 'approved'}``` | Отримано відповідь ```201 Created``` із тілом:<br />```{'id': 'ідентифікатор замовлення', 'status': 'confirmed', ...}```. |
| 7 | Надіслати `GET /api/orders/{id}` для створеного замовлення. | Отримано відповідь ```200 OK```. У деталях замовлення містяться коректні дані: термопляшка x 1 - клавіатура x 1, товари — 370000, знижка — 0, доставка — 8000, фінальна сума — 378000 копійок. |
| 8 | Надіслати `POST /api/products/{<ідентифікатор термопляшки>}/review` для створення відгуку із тілом запиту:<br />```{"rating":1,"text":"Поганий продукт, не рекомендую."}```. | Отримано відповідь ```201 Created```. Отримано тіло відповіді:<br />```{'review': {'rating': 1, "text": "Поганий продукт, не рекомендую.", ...}}``` |
| 9 | Надіслати `GET /api/products/{<ідентифікатор термопляшки>}/review` для отримання залишеного відгуку. | Отримано відповідь ```200 OK```. Отримано тіло відповіді:<br />```{'review': {'rating': 1, "text": "Поганий продукт, не рекомендую.", ...}}``` |
| 10 | Надіслати `POST /api/products/{<ідентифікатор клавіатури>}/review` для створення відгуку із тілом запиту:<br />```{"rating":5,"text":"Клавіатура клас, думаю замовити ще одну."}```. | Отримано відповідь ```201 Created```. Отримано тіло відповіді:<br />```{'review': {'rating': 5, "text": "Клавіатура клас, думаю замовити ще одну.", ...}}``` |
| 11 | Надіслати `GET /api/products/{<ідентифікатор клавіатури>}/review` для отримання залишеного відгуку. | Отримано відповідь ```200 OK```. Отримано тіло відповіді:<br />```{'review': {'rating': 5, "text": "Клавіатура клас, думаю замовити ще одну.", ...}}``` |
