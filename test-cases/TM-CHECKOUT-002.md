# TM-CHECKOUT-002

**_Назва:_** Оформлення замовлення на 1500 грн. без промокоду та із безкоштовною стандартною доставкою (зміна кількості у кошику).

**_Пріоритет:_** Високий.

**_Тип_**: позитивний, наскрізний UI-сценарій.

**_Покриття функціоналу:_** пошук та додавання товару в кошик, зміна кількості товару в кошику, перевірка порогу безкоштовної стандартної доставки (від 1500 грн), оформлення замовлення, робота з доставкою, пошук оформленого замовлення.

**_Передумови:_** сайт доступний; створено нове середовище; у каталозі доступні ```«Термопляшка 'Щодня'»``` за 500 грн (у кількості від 3 штук на складі).

**_Тестові дані:_** 3 термопляшки; без промокоду; стандартна доставка; ім'я «Олександр Тестовий»; електронна адреса ```test@example.test```; адреса «Київ, вул. Тестова, 12»; результат тестової оплати «Успішна оплата». Усі контактні дані вигадані.

| Крок | Дія | Очікуваний результат |
| ------------- | -------------- |--------------|
| 1 | У каталозі знайти термопляшку «Щодня» та відкрити картку товару. | У картці товару вказані наступні дані:<br />_Назва:_ ```Термопляшка «Щодня»```.<br />_Ціна:_ ```500,00 грн```. |
| 2 | Натиснути кнопку «До кошика» (кількість за замовчуванням — 1). | Лічильник кошика показує 1. |
| 3 | Закрити картку товару та відкрити кошик. | У кошику існує одна позиція термопляшки у кількості 1 шт., сума товарів — 500 грн. |
| 4 | У кошику збільшити кількість товару до 3 (використавши кнопку «+»). | Кількість позиції змінюється на 3 шт., сума товарів оновлюється до 1500 грн. Лічильник кошика показує 3. |
| 5 | Залишити поле промокоду порожнім та вибрати стандартну доставку. | Товари — 1500 грн; знижка — 0 грн; доставка — 0 грн (безкоштовно від 1500 грн); разом — 1500 грн. |
| 6 | Заповнити контактні поля тестовими даними; вибрати «Успішна оплата». | Дані прийнято, кнопка оформлення доступна, помилок валідації немає. |
| 7 | Один раз натиснути «Оформити замовлення». | Відображається повідомлення про успіх; відкривається «Мої замовлення»; створено рівно одне замовлення зі статусом «Підтверджено» та сумою 1500 грн; лічильник кошика — 0. |
| 8 | Відкрити «Деталі замовлення». | Термопляшка x 3; товари — 1500 грн, знижка — 0 грн, доставка — 0 грн. Відображається унікальний номер замовлення. |
| 9 | Перезавантажити сторінку та повторно відкрити кошик. | Те саме замовлення зберегло номер, статус і суму; дубліката немає; кошик порожній. |
