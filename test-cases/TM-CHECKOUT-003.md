# TM-CHECKOUT-003

**_Назва:_** Спроба застосування недійсного промокоду в кошику.

**_Пріоритет:_** Високий.

**_Тип:_** Негативний, UI-сценарій.

**_Покриття функціоналу:_** Робота з промокодами.

**_Передумови:_** Сайт доступний; середовище ініційовано; у кошику є хоча б один товар.

**_Тестові дані:_** Недійсний промокод ```INVALIDCODE```.

| Крок | Дія | Очікуваний результат |
| --- | --- | --- |
| 1 | Відкрити кошик із доданим товаром. | У кошику наявні товари з підсумковою сумою без знижки. |
| 2 | Ввести невірний промокод ```INVALIDCODE``` у відповідне поле та натиснути «Застосувати». | Система не застосовує знижку, з'являється інформативне повідомлення про помилку (недійсний або невідомий промокод). Запит повертає статус ```422```. |
| 3 | Перевірити фінальний розрахунок суми замовлення. | Сума до сплати не змінилася (знижка 0 грн), вартість розрахована коректно. |
