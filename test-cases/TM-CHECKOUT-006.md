# TM-CHECKOUT-006

**_Назва:_** API-оформлення замовлення із промокодом ```WELCOME10``` та стандартною доставкою.

**_Пріоритет:_** Високий.

**_Тип_**: позитивний, наскрізний API-сценарій.

**_Покриття функціоналу:_** створення середовища, перевірка каталогу, розрахунок кошика з промокодом (`POST /api/quote`), створення замовлення (`POST /api/orders`), перевірка деталей замовлення (`GET /api/orders/{id}`).

**_Передумови:_** API доступне; створено нове середовище через `POST /api/workspaces` (отримано валідний `X-Workspace-Token`); у каталозі (`GET /api/products`) доступна «Термопляшка 'Щодня'»  за 50000 копійок (500 грн).

**_Тестові дані:_** токен середовища; ; кількість: 1; промокод ```WELCOME10```; стандартна доставка (`delivery_type: "standard"`); ім'я «Олександр Тестовий»; електронна адреса ```test@example.test```; адреса «Київ, вул. Тестова, 12»; результат оплати `payment_result: "approved"`. Усі контактні дані вигадані.

| Крок | Дія | Очікуваний результат |
| ------------- | -------------- |--------------|
| 1 | Надіслати `GET /api/products` із параметром пошуку термопляшки. | Отримано відповідь ```200 OK```. У списку наявна термопляшка з ціною ```50000``` копійок (500 грн). Отримати поточний ідентифікатор термопляшки. |
| 2 | Надіслати `POST /api/quote` із тілом запиту: товар (qty: 1), промокод ```WELCOME10``` та стандартна доставка. | Отримано відповідь ```200 OK``` із розрахунком у копійках: товари — 50000, знижка — 5000 (10%), доставка — 8000 (стандартна), разом — 53000 (530 грн). |
| 3 | Надіслати `POST /api/orders` із повними даними замовлення (товар, купон, адреса, контактні дані, `payment_result: "approved"`). | Отримано відповідь ```201 Created```. Створено замовлення зі статусом ```confirmed``` та сумою ```53000``` копійок. Повернуто унікальний ідентифікатор замовлення (`id`). |
| 4 | Надіслати `GET /api/orders/{id}` для створеного замовлення. | Отримано відповідь ```200 OK```. У деталях замовлення містяться коректні дані: термопляшка x 1, товари — 50000, знижка — 5000, доставка — 8000, фінальна сума — 53000 копійок. |
| 5 | Надіслати `GET /api/quote` для перевірки стану після оформлення. | Отримано підтвердження, що кошик очищено. |
