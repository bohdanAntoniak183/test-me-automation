# TM-ISOLATION-001

**_Назва:_** Перевірка недоступності оформленного замовлення для інших середовищ.

**_Пріоритет:_** Високий.

**_Тип_**: негативний, API-сценарій.

**_Покриття функціоналу:_** створення середовища, ізоляція середовища.

**_Передумови:_** API доступне; створено два нових середовища через `POST /api/workspaces` (отримано валідні `X-Workspace-Token`); у каталозі (`GET /api/products`) доступна «Термопляшка 'Щодня'» .

**_Тестові дані:_** токени двох окремих середовищ; ім'я користувача ```«Олександр Тестовий»```; електронна адреса ```test@example.test```; адреса доставки ```«Київ, вул. Тестова, 12»````. Усі контактні дані вигадані.

| Крок | Дія | Очікуваний результат |
| ------------- | -------------- |--------------|
| 1 | Надіслати `GET /api/products` із параметром пошуку термопляшки, використовуючи токен для першого середовища. | Отримано відповідь ```200 OK```. У списку наявна термопляшка. Отримати поточний ідентифікатор термопляшки. |
| 3 | Надіслати `POST /api/orders` для першого середовища із тілом запиту:<br />```{'items': [{'product_id': '<змінити значення на ідентифікатор термопляшки>', 'quantity': 1}], 'name': 'Олександр Тестовий', 'email': 'test@example.test', 'address': "Київ, вул. Тестова, 12", 'delivery': 'standard', 'payment': 'approved'}``` | Отримано відповідь ```201 Created``` із тілом:<br />```{'id': 'ідентифікатор замовлення', 'status': 'confirmed', ...}```. |
| 4 | Надіслати `GET /api/orders/{ідентифікатор створеного замовлення}` використовуючи токен першого середовища. | Отримано відповідь ```200 OK``` із тілом:<br />```{'id': 'ідентифікатор замовлення', 'status': 'confirmed', ...}```. |
| 5 | Надіслати `GET /api/orders/{ідентифікатор створеного замовлення}` використовуючи токен іншого середовища середовища. | Отримано відповідь ```404 Not Found```. |
